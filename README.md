# 🚀 Next.js Auth + i18n + Theme Starter

A modern **Next.js 14+ App Router template** with authentication, internationalization, and dark mode support.

This starter is designed to be reused as a **foundation for SaaS apps, dashboards, and modern web applications**.

---

## ✨ Features

- 🔐 Authentication with NextAuth (Google provider)
- 🌍 Internationalization with `next-intl` (EN / ES ready)
- 🌗 Dark / Light mode with `next-themes`
- ⚡ App Router structure (`/app`)
- 🧩 Clean component-based architecture
- 🧭 Locale-based routing (`/[locale]`)
- 🎨 Tailwind CSS styling
- 🧱 Middleware-ready (route protection support)
- 📦 Prisma + Postgres ready
